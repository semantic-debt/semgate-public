# Third-party notices

semgate's evaluation sets are built from public datasets and repositories. This
file lists every source, its license, and the exact revision the importer uses.
Raw dataset files are downloaded at eval time into `evals/data/`, which is
git-ignored; they are not redistributed here. What the repository commits is the
converted eval cases (only when the source license allows it) plus manifests
that record source, revision, and input hashes.

The importer scripts are in `evals/`; each writes a manifest next to the data
and a copy under `evals/`. The revisions below are the pinned defaults in those
scripts and manifests.
